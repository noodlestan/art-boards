# @art-boards/switchboard-cli

> Switchboard CLI — multi-agent collaboration sessions over arbitrary artefacts.

## Setup

Run from the repository root (monorepo):

```bash
npm ci
```

## Verification

Run from the repository root (monorepo):

```bash
npm run lint
npm run ci
```
